# Keyboard Shortcuts

This document lists all available keyboard shortcuts in the ClipCash application.

## General

| Shortcut | Action |
|----------|--------|
| `Cmd/Ctrl + K` | Open command palette (search clips, navigate to pages) |
| `Cmd/Ctrl + U` | Navigate to Upload page |
| `?` | Show keyboard shortcuts help modal |
| `Escape` | Close any open modal (shortcuts help, command palette, etc.) |

## Navigation

| Shortcut | Action |
|----------|--------|
| `Cmd/Ctrl + E` | Navigate to Earnings page |
| `Cmd/Ctrl + P` | Navigate to Projects page |
| `Cmd/Ctrl + V` | Navigate to Vault page |

## Notes

- Shortcuts do not fire when focus is inside a text input or textarea
- `Cmd` refers to the Command key on macOS, `Ctrl` refers to the Control key on Windows/Linux
- Press `?` at any time to see the full list of shortcuts in a modal
- Use `Cmd/Ctrl + K` to quickly navigate to different pages using the command palette
