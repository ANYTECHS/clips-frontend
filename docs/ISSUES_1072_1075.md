# Issues 1072-1075

## Notifications (#1075)

Settings reads permission on mount and re-checks it when the tab regains focus, becomes visible, or the Permissions API reports a change. Denied permission is stored as the current browser state, so the app does not repeatedly prompt. The settings panel explains that notifications announce completed background renders and links to browser-specific settings where supported; Safari receives instructions because it does not reliably support deep settings URLs.

## Search (#1074)

Search normalizes case and punctuation, ranks exact, prefix, substring, and typo-tolerant fuzzy matches, and returns up to five suggestions. The command palette displays relevance scores and suggestions. Queries are debounced and cached by lowercase query.

## Rate limits (#1073)

Client timestamps exactly at `timestamp + windowMs` expire before the next request, allowing recovery at the boundary. Rate-limit events expose the reset time, retry delay, limit, and remaining count for status displays and monitoring. Server responses expose `X-RateLimit-*` and `Retry-After` headers.

## Safari wallet connection (#1072)

Passkey support is detected in the browser and requires a secure context. Safari and unsupported environments receive an actionable fallback to a browser wallet or Stellar key import. WebAuthn failures include browser and HTTPS guidance, while cancellation remains non-fatal.
