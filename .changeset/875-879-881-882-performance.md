Performance work across the dashboard, animations, uploads and monitoring.

- Isolate dashboard re-renders with fine-grained zustand selectors, memoised hook results and a stable sidebar context (#875).
- Drive progress bars on the compositor via `transform: scaleX()` instead of animating `width`, and add cancellable `useAnimationFrame` / `useAnimationFrameRate` hooks (#879).
- Add chunked, resumable uploads with per-chunk retry for files at or above 10MB, backed by new `/api/upload/chunk/*` routes (#881).
- Add Web Vitals and custom performance monitoring reporting to Sentry and product analytics, with budget-breach alerting (#882).
